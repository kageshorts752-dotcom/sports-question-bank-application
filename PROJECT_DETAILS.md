# Sports Question Bank Application

## Category
Question Bank & E-Learning

## Problem Statement
Store and organise questions by course, subject, unit, topic, type, marks and difficulty.

## Objectives
- Digitise question storage.
- Search and filter questions quickly.
- Classify questions using Bloom's Taxonomy.
- Generate a random question set.
- Export question data.

## Modules
1. Question Repository
2. Search and Filters
3. Question CRUD
4. Bloom Level & Difficulty
5. Random Question Set
6. CSV Export

## Database
Single `questions` table with primary key `id`.

## Innovative Feature
Random question-set generation with multi-level filtering and CSV export.

## Minimum Requirements Covered
The booklet specifies a repository, filters/search, tags, Bloom level, difficulty, marks and export question set for Project 15. This implementation provides those features.
